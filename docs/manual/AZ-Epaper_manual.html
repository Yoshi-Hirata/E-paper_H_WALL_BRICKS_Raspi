AZ-Epaper 展示 運用マニュアル

現場スタッフ向け。PC もルーターも無い会場で、radxa（衣装の後ろの小さなコンピュータ）だけで展示ショーを回すための手順です。操作はすべて radxa-05 の小さな画面とボタンで行います。

しくみ機体と衣装ボタン開場運用中閉場停電・ブレーカー困ったときデータを戻すスマホ操作禁止事項

全体のしくみ

  • radxa-05 が親機。Wi-Fi「AZ-Epaper」を自分で出し、ショーの進行（いつどの絵に切り替えるか）と音楽（Bose スピーカー）を受け持ちます。衣装はつながっていません。
  • ほかの 7 台が子機。それぞれ 1 着の衣装につながり、親機の合図で絵を切り替えます。電源が入ると自動で AZ-Epaper に入ります。
  • 衣装の基板と radxa は全部同じ電源。ブレーカー（根元のコンセント）ひとつで一斉に入り、一斉に切れます。
  • Bose スピーカーは radxa-05 の USB-C から給電されています。ただし Bose は自分の電池を持っているので、電源の入／切は Bose 本体の電源ボタンで行います（ブレーカーを切っても電池で動き続けます）。
  • ショーの絵はあらかじめ各衣装に書き込み済みです。電源が落ちても消えません。
  • ショーは約 11 分。LOOP が入っていると、終わるたびにすぐ最初から繰り返します（最初の絵 → 3 秒カウントダウン → 音楽と本編）。

電源が何度落ちても、ショーのデータは消えません。電源が戻ったら、親機の画面から START するだけで再開できます。

ボタンの基本

各 radxa の画面の横にボタンがあります。

▲▼◀▶ ジョイスティック

上下で項目を選ぶ。EXHIBITION 画面では左右で音量。

KEY1 決定 / 実行

メニューの項目に入る。START・STOP などは長押し（約 1 秒）。

KEY2 戻る

前の画面・メニューに戻る。

KEY3 画面を消す

EXHIBITION 画面では長押しで LOOP の入／切。

  • 「長押し」は約 1 秒押し続けること。大事な操作（START、STOP、Wi-Fi 切替、データを戻す）は、ぶつかっても起きないよう全部長押しです。
  • 画面が暗いとき、最初の一押しは画面を点けるだけで、何も実行されません。
  • 画面に buttons locked と出たら、KEY2 → KEY3 → KEY2 を 5 秒以内に押すと一時的に解除されます（1 分さわらないと元に戻ります）。

開場の手順 毎朝

会場では、衣装の基板と radxa（radxa-05 を含む全台）が同じ電源につながっています。ブレーカー（または根元のコンセント）を入れると、すべてに同時に電気が入ります。

  1. ブレーカー（根元のコンセント）を入れる。衣装と radxa が一斉に起動し、Bose への給電（充電）も始まります。

  2. Bose の電源ボタンを押して電源を入れる（すでに点いていればそのまま）。

  3. 何もさわらずに 3 分待つ。radxa-05 が Wi-Fi AZ-Epaper を出すまで約 2 分、子機はそれが出るまで自動で待ち続け、出たら順に入ってきます。スピーカーも自動でつながります。

  4. radxa-05 の画面で確認する。メニューで EXHIBITION を選んで KEY1。

    • units 8/10 online … 親機と子機 7 台、計 8 台がそろっている（radxa-06・08 は使わないので 10 台中 8 台が正常）。そろうまで少し待つ
    • speaker ok · vol 70% (bluez) … スピーカーにつながっている
    • LOOP on … 繰り返し再生が入っている（LOOP off なら KEY3長押し）

  5. KEY1長押し で START。preset… 5/7 painted（全衣装に最初の絵を描いている）→ カウントダウン 3 秒 → 0:00 で音楽と本編が始まります。

自動では始まりません。電気が入ったあと、必ず START を押してください。8 台そろわない、スピーカーがつながらない場合は 困ったとき へ。

閉場の手順 毎晩

  1. radxa-05 の EXHIBITION 画面で KEY1長押し → STOP。大きい行が idle になるのを確認。

  2. 10 秒ほど待ってから、ブレーカー（根元のコンセント）を切る。衣装と radxa が一斉に止まります。衣装の絵は最後の状態のまま残ります。

  3. Bose の電源ボタンを押して切る。ブレーカーを切っても Bose は電池で点いたままなので、必ず本体で切ってください（翌朝の電池切れ防止）。

STOP せずにブレーカーを切ってもデータは壊れませんが、STOP してから切ると翌朝の確認が確実です。

停電・ブレーカーが落ちたとき

全部が同じ電源なので、停電すると衣装も radxa も一斉に止まり、電気が戻ると一斉に起動します。開場と同じ流れです。データは消えません。

  1. 電気が戻ったら、何もさわらずに 3 分待つ。radxa-05 の Wi-Fi が出て、子機が自動で戻ってきます。Bose は停電中も電池で点いたままなので、radxa-05 が起動すると自動でつなぎ直します（Bose が消えていたら電源ボタンで入れる）。

  2. radxa-05 の EXHIBITION 画面で units 8/10 online と speaker ok を確認。

  3. 大きい行が idle なら KEY1長押し で START。自動では再開しません。

停電の直後にまた停電しても問題ありません。電気が戻るたびにこの 3 つを繰り返してください。START で ERROR … Upload … と出たときは、衣装の絵の書き込み直しが必要です。スマホ操作 の「書き込み直し」を行うか、責任者に連絡してください。

ショーのデータを前の状態に戻す

radxa-05 はショーのデータを自動で控えています（最新 5 つ ＋ 衣装に書き込まれている版）。停電でデータが壊れた、間違えて変えてしまった、というときにその場で戻せます。PC は要りません。

  1. EXHIBITION 画面で、上演中なら KEY1長押し で STOP。

  2. ▼ を押すと BACKUPS ページ。10-01 15:20 upload * のように並び、*（緑）が衣装に書き込まれている版です。最初からこの行が選ばれています。

  3. ▲▼ で選び、KEY1長押し。hold KEY1 again to restore … と出たら、5 秒以内にもう一度 KEY1長押し。

  4. 結果を見る:

    • restored - units already hold it … そのまま START してよい
    • restored - Upload needed … 衣装の書き込み直しが必要（スマホ操作 または責任者へ）
    • already the workspace - nothing restored … すでにその状態（何も変わらない）

  5. KEY2 で EXHIBITION 画面に戻る。

パスワード・音量などの設定は戻りません（変わりません）。

スマホから操作する 責任者向け

書き込み直し（Upload）など、radxa の画面だけではできない操作に使います。

  1. スマホの Wi-Fi を AZ-Epaper につなぐ（パスワード: 別紙参照）。

  2. ブラウザで http://10.42.0.1:8765 を開く。最初の操作でパスコードを聞かれます（別紙参照。一度入れれば覚えます）。

  3. 書き込み直し: radxa-05 の画面で STOP → スマホの THE SHOW タブで ① Upload → 全衣装が書き込み済みになるまで待つ（1〜2 分）→ radxa-05 の画面で START。

Wi-Fi のパスワードとパスコードは来場者に教えないでください。つないだ人なら誰でもショーを止められます。

やってはいけないこと

  • 子機（衣装側の radxa）の画面で KEY2 を押さない。上演中の子機は REMOTE 画面になっており、KEY2 を押すとその衣装だけショーから外れて止まります。
  • radxa と衣装の組み合わせを変えない。変えたら必ず責任者へ。
  • Bose を来場者や別のスマホとペアリングしない。音が radxa-05 から出なくなります。
  • radxa-05 に衣装をつながない（親機は衣装なし）。
  • PC やもう一台のパソコンから同時に操作しない（会場では PC は使いません）。
